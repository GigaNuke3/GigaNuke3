# About Me:
<h3>Hi, I'm <strong>Eco</strong> — a Junior Full Stack Developer pursuing AI Engineering.</h3>

I'm interested in building software that combines <strong>desktop applications, local AI, and practical engineering.</strong>

I started with web development using <strong>JavaScript, PHP, Laravel, MySQL, HTML, and CSS</strong>, but over time I found myself more interested in building <strong>local-first applications</strong> and understanding how things work underneath the interface.

Currently, I'm exploring <strong>AI Engineering</strong>, especially <strong>local LLMs, Ollama, AI memory, embeddings, and integrating AI into applications.</strong>

I enjoy building things from scratch, experimenting with new ideas, reverse-engineering my own projects, and learning through actually breaking and rebuilding things.
